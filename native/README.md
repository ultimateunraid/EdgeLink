# EdgeLink Native — experimental port
Copy only EdgeLinkNative into the Forever Interface/AddOns folder. Disable the legacy EdgeLink addon and exit its companion before testing. Run /edgenative to toggle the draggable preview. This prototype does not span monitors yet. Session shows FPS, gold and XP; Map shows zone name; Quests is a placeholder. No capture, synthetic input, HTTP or external data bridge is used by this prototype.

The legacy code remains in this branch for reference and is NOT the native release. Do not package it as a compliance-first build. No Blizzard approval or in-client validation has been obtained.
