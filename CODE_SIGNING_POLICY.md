# Code signing policy

Status: **not signed yet.** An application to the SignPath Foundation open-source programme is planned. Until it is approved, release files are unsigned and Windows or your antivirus may warn about them.

Once approved, this statement will apply:

> Free code signing provided by [SignPath.io](https://signpath.io/), certificate by [SignPath Foundation](https://signpath.org/).

## What is signed

Only `EdgeLink.exe` and the installer `EdgeLink-Setup-<version>.exe`, both built by GitHub Actions from this repository (`.github/workflows/build.yml`). No file built on a personal computer is signed.

## Team roles

- Committers and reviewers: [members of the ultimateunraid organization](https://github.com/orgs/ultimateunraid/people)
- Approvers: [owners of the ultimateunraid organization](https://github.com/orgs/ultimateunraid/people?query=role%3Aowner)

## Privacy

EdgeLink does not collect or send personal data. See [Privacy](README.md#privacy) for the two kinds of outbound request it makes (item icons and map art).
